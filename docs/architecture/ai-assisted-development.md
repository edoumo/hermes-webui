# 🤖 AI-assisted development

The experimental Hermes Harness UI work in this branch was developed with
substantial AI assistance, including architecture exploration, code authoring,
test design and documentation drafting with OpenAI ChatGPT.

The work remains **human-directed and human-reviewed**. Project scope,
security boundaries and acceptance decisions are owned by the maintainer, and
H3 through H5 were qualified against the real Hermes API/runtime rather than
accepted from generated tests alone. H6 keeps the same rule: AI-assisted code
is not considered validated until repository tests and integration evidence
pass.

This disclosure applies only to the Harness/Durable Workers contribution on
the experimental branches. It does not make any claim about the authorship of
unrelated upstream Hermes WebUI code.

The robot marker lives in documentation rather than source comments so the
implementation remains conventional and easy to review.
